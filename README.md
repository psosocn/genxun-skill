# 寻根 · Genealogy Skill

豆包 AI 寻根问祖技能：输入老家地名+姓氏，自动生成带历史时间轴、迁徙路线、宗族典故的古朴 HTML 寻根报告。

## 安装

1. 点右上角 Code → Download ZIP
2. 解压后，把 `寻根` 文件夹放到豆包的 `.user_skills/` 目录
3. 重启豆包，说"我老家XX省XX县XX村，姓X"即可触发

## 目录结构

```
寻根/
├── SKILL.md
├── scripts/
│   ├── build_queries.py
│   └── render_report.py
└── references/
    ├── methodology.md
    ├── migration_routes.md
    └── output_template.md
```
