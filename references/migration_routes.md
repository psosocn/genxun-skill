# 中国历史上的主要移民路线（寻根高频）

用户说"祖上从XX迁来"时，对照这张表判断时代和中转地。

## 1. 江西 → 两湖（江西填湖广）
- **时间**：元末明初（洪武大移民）
- **中转地**：江西饶州府鄱阳县瓦屑坝（今上饶鄱阳）
- **迁入**：湖北东部、东部、安徽西部（鄂东、皖西）
- **对应姓氏**：鄂东程、张、陈、王、李等大姓
- **口传线索**："江西瓦屑坝""筷子巷""江西老表"

## 2. 山西 → 华北（洪洞大槐树）
- **时间**：明初
- **中转地**：山西洪洞县大槐树广济寺
- **迁入**：河南、河北、山东、安徽北部
- **口传**："大槐树老鸹窝""小脚趾两半"

## 3. 广东南雄珠玑巷 → 珠三角
- **时间**：唐宋
- **迁入**：广州、佛山、中山、江门
- **姓氏**：陈、黄、李、梁等珠三角大姓

## 4. 福建石壁 → 客家
- **时间**：唐宋
- **中转**：福建宁化石壁
- **迁入**：闽西、粤东、台湾
- **口传**："石壁公"

## 5. 山东 → 东北（闯关东）
- **时间**：清中后期至民国
- **迁入**：辽宁、吉林、黑龙江
- **口传**："小云南""闯关东"

## 6. 湖广 → 四川（湖广填四川）
- **时间**：清初
- **迁入**：四川、重庆
- **来源**：湖北、湖南、广东、江西

## 使用要点
- 用户说"祖上江西"，先问是不是"瓦屑坝/饶州"
- 用户说"祖上山西"，先问是不是"洪洞大槐树"
- 不要把不同移民路线混为一谈
